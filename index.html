NIRUNE

NIRUNE is a music application for Windows and Android. It brings local audio files and music catalogs connected by the user into one interface.

Application name: NIRUNE

Application purpose: Give users one place to browse, search, organize, and play music from supported local and connected sources.

What is NIRUNE?

The purpose of NIRUNE is to provide one place to browse, search, organize, and play music from supported sources. Users can add local music folders, play local tracks, connect Google through OAuth, and search the official YouTube catalog. Provider capabilities remain clearly identified so the application only offers actions that each connected source supports.

Current functionality

01

Local music

Add folders, search your local library, and play audio files on Windows.

02

Connected catalogs

Connect Google through OAuth and submit explicit searches to the official YouTube Data API.

03

Source-aware design

Online playback is offered only when an authorized provider source supports it.

Data and privacy

The preview has no NIRUNE cloud account or analytics service. Library data and provider credentials remain on the device. Google credentials are kept in platform-secure storage and deleted from NIRUNE when the provider is disconnected.

Read the Privacy Policy

How NIRUNE uses Google user data

Connecting Google is optional and starts only when the user selects Connect Google. NIRUNE requests basic Google profile and email information to identify the connected account. It requests read-only YouTube access through youtube.readonly to send catalog searches explicitly submitted by the user and display the resulting YouTube metadata inside NIRUNE.

NIRUNE does not create, modify, or delete YouTube data. Google credentials are stored in platform-secure storage on the user's device and are deleted from NIRUNE when the user disconnects Google. The NIRUNE Privacy Policy describes access, use, retention, sharing, and deletion in detail.

Availability

NIRUNE currently runs as a limited preview while its Windows and Android integrations are developed. This public website identifies the application, explains its functionality, and documents its data practices.
